# Installation modes and task selection

The system offers 3 installation options:
minimal
server
desktop

## Mode selection

The installer runs non-interactively. The mode is fixed by the PYNTARA_INSTALL_MODE environment variable.

When PYNTARA_INSTALL_MODE is omitted, the mode is auto-detected from the system:
on desktop systems, desktop mode is used
on server systems, server mode is used

Deprecated (for reference only): the interactive selection screen and the
DIALOG_TIMEOUT auto-selection countdown do not work and their development is
stopped. PYNTARA_DEFAULT_INSTALL_MODE still fixes the default for auto-detection.

## Task selection

The task set is fixed by the PYNTARA_TASKS environment variable: space-separated
task names. Dependencies are still resolved before export, so the effective set
is always complete and ordered.

When PYNTARA_TASKS is omitted, the default task set of the chosen mode is used:
the tasks whose modes field lists that mode.

Each task has:
explicit ordering
name
human-readable description

Task set and metadata are defined in tasks.yaml. The default checked tasks for
the selected mode are the tasks whose modes field lists that mode; the task
catalog command is generated by the Python task-catalog command, so the shell
never parses the catalog.

Deprecated (for reference only): the dialog --checklist selection screen with
TASK_TIMEOUT auto-accept and the SLEEP_AFTER_IMPORTANT_MESSAGE fallback pause
do not work and their development is stopped.
